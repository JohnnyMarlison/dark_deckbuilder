# ⚔️ Dark Deckbuilder (Тёмный Колодострой)

**Dark Fantasy Roguelike Deckbuilder**, написанный на **Python** с использованием графической библиотеки **Arcade**.

Соберите уникальную колоду, проложите путь через три мрачных мира, сразитесь с элитными монстрами и древними боссами и откройте все карты, противников и достижения.

---

## ✨ Особенности игры

* **4 игровых класса** со своими стартовыми колодами, характеристиками и стилем боя:
  * **Воин** — мастер брони, сокрушительных атак и ударов от защиты.
  * **Элементалист** — повелитель стихий, управляющий заклинаниями и стаминой.
  * **Паладин** — хранитель света, сочетающий исцеление, защиту и возмездие.
  * **Ассасин** — быстрый боец тени с пробиванием брони, добором и серией атак.
* **3 мира и система прогрессии (НГ+):** каждый мир состоит из трёх этапов с нарастающей сложностью, уникальными локациями и боссами в финале.
* **Энциклопедии и прогресс:**
  * **Бестиарий** — открывайте встреченных врагов и изучайте их характеристики.
  * **Каталог карт** — просматривайте все доступные и скрытые карты по классам.
  * **Рекорды и достижения** — система внутриигровых достижений с всплывающими уведомлениями и таблицей побед по персонажам.
* **Собственный графический и аудио-движок:** процедурная отрисовка карточек, аватаров, эффектов снарядов, анимаций интерфейса и синтезированных звуковых эффектов.

## 🗂️ Архитектура проекта

```text
dark_deckbuilder/
├── main.py          # Точка входа и главное окно игры (GameWindow)
├── config.py        # Настройки экрана, цветовая палитра и пути ресурсов
├── cards.json       # База данных карт
├── records.json     # Сохранения прогресса, открытых карт и достижений
├── core/            # Игровая логика: боевой движок, карты, эффекты, герои, враги
├── data/            # JSON-конфигурации противников, боссов и локаций
├── views/           # Экраны игры: главное меню, выбор героя, бой, награды, пауза
└── visuals/         # Рендеринг виджетов карт, спрайтов, иконок, локаций и VFX
```

## 🚀 Установка и запуск из исходников

1. Убедитесь, что у вас установлен **Python 3.11+**.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd dark_deckbuilder
   ```
3. Установите библиотеку `arcade`:
   ```bash
   pip install arcade
   ```
4. Запустите игру:
   ```bash
   python main.py
   ```

## 🎮 Управление

* **ЛКМ** — выбор и розыгрыш карт, взаимодействие с кнопками интерфейса.
* **Колёсико мыши** — прокрутка карт в каталогах, колоде добора и стопке сброса.
* **Space / Enter** — завершить ход игрока.
* **ESC** — открыть/закрыть меню паузы или закрыть модальное окно.
